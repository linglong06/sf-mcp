# EC interface inventory and related data

`list_entities` discovers entity sets from the authenticated tenant's OData service document, accepting both the top-level and verbose `d` forms. An unexpected shape returns an error, never an invented empty list. `get_entity_catalog` pages over that list, reading individual metadata documents and returning per-entity metadata status and field counts. Category labels use name heuristics; this is an inventory of exposed sets, not a definitive list of EC features. Service document and metadata visibility do not prove read/write privileges. Service-document and metadata cache entries are isolated by instance, API host and credential digest; they remain snapshots subject to configured TTL.

`query_odata` accepts `as_of_date`, `from_date`, `to_date` and `filter_parent_date`. Use ISO dates (`YYYY-MM-DD`); `as_of_date` and a range are mutually exclusive. SAP applies date parameters according to the entity and navigation semantics; `filter_parent_date` applies only where supported. Consult SAP's effective-dating documentation. Pagination uses the same request parameters for subsequent pages.

Related data tools: `get_emergency_contacts`, `upsert_emergency_contact`, `get_person_relationships`, `upsert_person_relationship`, `get_payment_information`, `upsert_payment_information`, `upsert_payment_detail`, `upsert_payment_detail_country`, `get_attachment`, and `create_attachment`. All writes default to `dry_run=true` and require `SF_ALLOW_WRITE=true` to send. A preview builds a request but does not validate SAP rules, permissions or data. Treat partial write failures as partial state and verify before retrying.

Relationship writes do not create a dependent person. The payment parent and detail are separate calls, not an atomic hire/payment workflow; the country-specific tool needs existing parent keys, and only works where the tenant exposes the country entity with matching keys. Tenant rules may require a different write sequence or nested payload. `create_attachment` accepts base64 (maximum 5 MiB); its dry-run output contains the content. Creating an attachment does not link it to an employee or guarantee the module supports a specific attachment purpose. `get_attachment` returns content only when explicitly requested. These tools disable parameter logging, but the MCP response contains sensitive information and must be handled accordingly.

Reads and the entity inventory have been tested against a preview tenant; write paths have automated mocked/preview tests only. Actual permissions, fields, workflows, country availability, and write behavior require tenant-specific validation. No actual bank, family, or attachment writes were performed in testing.
